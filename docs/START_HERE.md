## 🆘 اگر کچھ غلط ہے

### 404 ہے

```
1. Vercel میں Deployments دیکھیں
2. Build log میں errors
3. Local میں: npm run build
```

### Upload نہیں ہو سکا

```
1. GitHub Desktop دوبارہ کوشش کریں
2. یا Terminal استعمال کریں
3. یا GitHub web interface میں drag-drop کریں
```

### Deploy نہیں ہوا

```
1. .next folder delete کریں
2. node_modules delete کریں
3. npm install دوبارہ
4. Vercel میں "Redeploy" کلیک کریں
```

## 💡 Pro Tips

```
1️⃣ Git Regularly
   git add . → git commit → git push
   ہر چھوٹی بھی تبدیلی کریں

2️⃣ Vercel Auto-Deploys
   Git push کرو → Vercel خود deploy کرے

3️⃣ Environment Variables
   Sensitive data .env میں رکھیں
   .gitignore میں شامل کریں

4️⃣ Domain Setup
   بعدوں custom domain شامل کر سکتے ہو
   Vercel → Settings → Domains

5️⃣ Analytics
   Vercel Analytics شامل کریں
   دیکھیں کون visit کر رہا ہے
```
