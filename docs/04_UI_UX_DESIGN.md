## 1. Design System

### رنگ‌ها

**Dark Mode Palette (اولویت)**
```

Error:                 #EF4444 (قرمز)

Text Secondary:        #A0AEC0

Glassmorphism:
├── Glass Background:   rgba(255, 255, 255, 0.05)
├── Glass Border:       rgba(255, 255, 255, 0.1)
└── Glass Blur:         12px backdrop-filter

Node Colors (mastery-based):
├── 🟢 High:    #10B981 (80-100%)
├── 🟡 Medium:  #FBBF24 (50-79%)
├── 🟠 Weak:    #FB923C (20-49%)
```
