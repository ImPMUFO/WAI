# WAIMA

**من کیستم؟**  
**ترسیم‌گر ذهنی**

سایت زندهٔ یادگیری و خودشناسی:  
با گفتگو دانش را می‌سنجیم، نقشهٔ ذهن را می‌سازیم و با بازی و پیشرفت، مسیر رشد را روشن می‌کنیم.

🌐 نسخهٔ آنلاین: [https://waima.vercel.app](https://waima.vercel.app)

---

## WAIMA چیست؟

WAIMA فقط یک چت‌بات نیست.

اینجا کاربر می‌فهمد:

- چه چیزهایی را واقعاً بلد است
- کجاها دانشش سطحی یا ناقص است
- قدم بعدی یادگیری‌اش چیست
- مسیر رشدش در طول زمان چطور پیش رفته

همه‌چیز در یک تجربهٔ واحد جمع شده:  
گفتگو · نقشه ذهنی · بازی · سطح و امتیاز · پوستهٔ ظاهری · گفتگوی جهانی

---

## امکانات اصلی

### گفتگو با WAIMA
همراه یادگیری با لحن خودمونی و منطقی  
پاسخ مرتبط با موضوع گفتگو  
معرفی گاه‌به‌گاه کتاب مرتبط با مسیر یادگیری  

### نقشه ذهنی
نمایش دانش به‌صورت زنده و یکپارچه  
گره‌های آشنا، نزدیک و دور  
به‌روزرسانی پس از گفتگو و فعالیت‌های مرتبط  
خروجی تصویری و سندی از نقشه  

### بازی‌ها
کوئیز چهارگزینه‌ای  
بازی‌های جانبی آموزشی  
XP و سطح  
جدول امتیازات  

### حساب کاربری
ثبت‌نام با **آیدی** (حروف کوچک انگلیسی، عدد و خط زیر)  
پروفایل، آواتار و بیوگرافی  
همگام‌سازی اطلاعات با Supabase  

### گفتگوی جهانی
فضای متنی عمومی بین کاربران  
استیکرهای پیش‌فرض سایت  
ویرایش و حذف پیام خود  

### پوسته‌های ظاهری
اصلی · روز · دریایی · آتشین · کهکشانی · چوبی  

اشیا و انیمیشن‌های تزئینی فقط در صفحهٔ اول فعال‌اند  
تا در صفحات گفتگو و نقشه مزاحم نباشند.

### چندزبانه
🇮🇷 فارسی · 🇺🇸 English · 🇸🇦 العربية

## اجرا روی سیستم خودت

```bash
git clone https://github.com/ImPMUFO/WAI.git
cd WAI
cp .env.example .env.local
npm install
npm run dev
```

سپس باز کن:

[http://localhost:3000](http://localhost:3000)

---

## متغیرهای محیطی

این مقادیر را در `.env.local` و در تنظیمات Vercel وارد کن:

| متغیر | نقش |
|--------|------|
| `GEMINI_API_KEY` | کلید Google Gemini از AI Studio (الزامی) |
| `GEMINI_MODEL` | پیش‌فرض: `gemini-2.0-flash` |

---

## دیتابیس (Supabase)

1. یک پروژه در Supabase بساز  
2. محتوای فایل `supabase/schema.sql` را در SQL Editor اجرا کن  
3. آدرس و کلید anon را در متغیرهای محیطی بگذار  

ورود کاربران بر پایهٔ آیدی است؛  
تنظیمات تأیید ایمیل را متناسب با همین مدل در پنل Auth بررسی کن.

## ساختار پروژه

```text
src/app/              صفحات، APIها و مسیرها
src/components/       رابط کاربری (تم، منو، گربه، بازی‌ها و …)
src/lib/              منطق، i18n، گیمیفیکیشن، همگام‌سازی
src/content/          محتوای قابل ویرایش (مثل ارتباط با ما)
supabase/             اسکیمای پایگاه داده
```

---

## استقرار روی Vercel

1. ریپوی GitHub را به Vercel وصل کن  
2. همان متغیرهای محیطی را در Project → Settings → Environment Variables بگذار  
3. Deploy کن  

بعد از هر Push روی شاخهٔ اصلی، نسخهٔ جدید ساخته می‌شود.
