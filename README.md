# WAIMA

**من کیستم؟**  
**ترسیم‌گر ذهنی**

پلتفرم فارسی برای یادگیری از طریق گفت‌وگو، نقشه ذهن، بازی آموزشی و پیشرفت شخصی.

---

## ایده

کاربر در یک حوزه گفت‌وگو می‌کند؛ سیستم می‌کوشد بفهمد چه چیزهایی را عمیق می‌داند، کجاها سطحی است، و قدم بعدی چیست.  
خروجی مهم: **نقشه ذهن** با لایه‌های معلوم، نزدیک و افق (مه).

---

## قابلیت‌های فعلی

| بخش | توضیح |
|-----|--------|
| گفتگوی ارزیابی | چت هوشمند با GapGPT / OpenAI-compatible |
| نقشه ذهن یکپارچه | نقشه واحد + زوم و درگ |
| حساب کاربری | ثبت‌نام، ورود، تأیید ایمیل، خروج (Supabase) |
| ذخیره ابری | گفتگو و نقشه برای کاربر لاگین‌شده |
| گیمیفیکیشن | XP، سطح، مأموریت |
| بازی آموزشی | `/play` |
| پوسته‌های ظاهری | ۶ پوسته |
| زبان | سوییچر پایه fa / en / ar |
